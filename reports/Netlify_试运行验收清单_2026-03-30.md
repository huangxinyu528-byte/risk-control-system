# Netlify 试运行验收清单

日期：2026-03-30  
适用范围：风控系统第一版 Netlify 试运行环境

## 一、前端页面验收项

### 1. 登录页
- 站点首页可进入登录页
- 输入试运行密码后可进入系统
- 登录失败时提示正常

### 2. 客户总账页
- `/customers` 可正常打开
- 页面不白屏、不报 500
- 搜索、筛选、展开项目可正常使用
- 不出现 `合计 / 单位 / 购货单位` 这类噪声主体

### 3. 客户详情页
- 从客户总账页进入客户详情页正常
- 原始档案页可打开
- 多 sheet 客户可切换
- 原始布局预览可正常展示

### 4. 风控总览页
- `/risk` 可正常打开
- 核心指标卡可正常显示
- Top 客户、Top 项目列表可正常显示
- `newAlertCount` 不再为 `null`

### 5. 风险客户列表页
- `/risk/customers` 可正常打开
- 风险等级、风险原因、建议动作显示正常
- 筛选和排序可用
- 点击客户名称可进入详情页

### 6. 风险项目列表页
- `/risk/projects` 可正常打开
- 项目风险字段显示正常
- 项目归属筛选为结构化选项
- 点击项目名称可进入客户详情页并带 `projectId`

## 二、API 验收项

### 核心接口
以下接口应返回 `200` 且为有效 JSON：
- `/api/customers`
- `/api/customers/ledger`
- `/api/risk/overview`
- `/api/risk/customers`
- `/api/risk/projects`

### API 数据要求
- 风险等级由后端返回，不由页面自己拼
- 风险原因由后端返回，不由页面自己拼
- 建议动作由后端返回，不由页面自己拼
- 关键接口在试运行环境下必须能访问真实数据库数据

## 三、登录验收项

### 1. 访问控制
- Netlify 站点访问保护可用（如启用）
- 系统内登录密码可用
- 未授权访问不可直接进入系统主页面

### 2. 登录后链路
- 登录后可进入客户总账页或系统主页面
- 登录态在刷新后行为符合预期

## 四、风控模块验收项

### 1. 风控规则结果
- 风险总览页能展示真实指标
- 风险客户页能展示客户风险原因
- 风险项目页能展示项目风险原因和命中规则

### 2. 当前关键整改项复验
- `待补数据` 不再污染主展示
- `当前未发现明显异常` 不再和明确风险原因并列
- `R-009` 为补强后的版本
- 项目归属筛选已结构化
- Top 客户排序已优化
- `newAlertCount` 已有稳定统计口径

## 五、联动与跳转验收项

- 风控总览页 -> 风险客户页
- 风控总览页 -> 风险项目页
- 风险客户页 -> 客户详情页
- 风险项目页 -> 客户详情页
- 风险项目页 -> 客户详情页并带 `projectId`

## 六、已知限制项

### 本次试运行不建议纳入正式验收范围
- 在线 Excel 导入
- 本地脚本型批处理
- 预警记录页
- 风险规则配置页

### 特别说明
- `app/api/import/excel/route.ts` 依赖 Python、子进程和临时文件，不建议作为 Netlify 试运行能力验证项

## 七、验收结论建议

当以下条件全部满足时，可判定 Netlify 试运行环境可用：
- 登录正常
- 客户主链路正常
- 风控三页正常
- 核心 API 正常
- 关键跳转正常
- 数据来自真实试运行数据库
