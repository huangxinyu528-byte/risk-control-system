# 正式数据版上线执行总表_2026-03-30

## 阶段1：正式数据库准备

### 目标
- 准备一套可供 Netlify 正式访问的 PostgreSQL 数据库
- 拿到正式环境可用的数据库连接串
- 确认 Prisma 结构可落到正式库

### 具体操作项
- 选择正式 PostgreSQL 托管服务
- 创建正式数据库实例
- 创建数据库账号与权限
- 开启公网访问或允许 Netlify 访问
- 获取正式 `DATABASE_URL`
- 在正式 `DATABASE_URL` 下执行 Prisma migration
- 确认核心表创建成功

### 负责人建议
- 我：确认业务需要的核心表和上线范围
- Codex：协助核对 Prisma 结构、migration、环境变量
- 运维：创建数据库、配置访问策略、保管连接串

### 完成标准
- `DATABASE_URL` 已可用
- Prisma migration 执行成功
- 核心表存在：
  - `customers`
  - `projects`
  - `contracts`
  - `receivables`
  - `customer_ledger_profiles`
  - `customer_ledger_rows`
  - `risks`
  - `credit_scores`

### 风险点
- 数据库只在本地或内网，Netlify 无法访问
- SSL/TLS 未配置，线上连接失败
- migration 版本与当前代码不一致

### 回滚点
- 暂不切线上环境变量
- 保留正式库空库初始状态或建库快照

## 阶段2：本地真实数据迁移演练

### 目标
- 把本地真实数据完整迁到正式数据库
- 先做一轮演练，验证结构和数据都能对上

### 具体操作项
- 从本地数据库导出：
  - 客户
  - 项目
  - 合同
  - 应收
  - 风险记录
  - 信用评分
  - 完整账款档案
- 先导入主数据：
  - `customers`
  - `projects`
  - `contracts`
  - `receivables`
- 再导入档案数据：
  - `customer_ledger_profiles`
  - `customer_ledger_rows`
- 再导入风控与辅助数据：
  - `risks`
  - `credit_scores`
  - `collection_tasks`
  - `monthly_reports`
  - `customer_merge_mappings`
- 抽样核验重点客户和项目

### 负责人建议
- 我：确认抽样客户/项目名单
- Codex：协助整理迁移顺序、核验字段与页面映射
- 运维：执行导出导入脚本或数据库迁移命令

### 完成标准
- 正式库数据量与本地核心表基本一致
- 客户详情页所需档案表数据完整
- 抽样项目能在数据库中查到真实档案：
  - 云龙小学
  - 96#地块
  - 青水澜湾

### 风险点
- 先导档案后导主数据，造成外键关系错乱
- `customer_ledger_profiles` 与 `customer_ledger_rows` 关联不完整
- JSON 字段导入后结构损坏

### 回滚点
- 删除正式库本轮导入数据
- 恢复到 migration 后、导入前状态

## 阶段3：Netlify 接正式数据库

### 目标
- 让 Netlify 运行环境正式连接真实数据库
- 主链路 API 真实数据库优先

### 具体操作项
- 在 Netlify 配置环境变量：
  - `DATABASE_URL`
  - `SITE_ACCESS_PASSWORD`
- 触发一次正式数据版部署
- 查看构建日志
- 查看 Runtime 日志
- 确认关键 API 返回正式数据库数据，而不是 fallback

### 负责人建议
- 我：确认部署批次和上线窗口
- Codex：协助核对环境变量、构建日志、关键 API 回归
- 运维：在 Netlify 后台配置变量并触发部署

### 完成标准
- Netlify 构建通过
- 无 Prisma 初始化错误
- 无数据库连接错误
- 关键接口可用：
  - `/api/customers`
  - `/api/customers/ledger`
  - `/api/customers/[id]/full-profile`
  - `/api/customers/[id]/account-ledger-profile`
  - `/api/risk/overview`
  - `/api/risk/customers`
  - `/api/risk/projects`

### 风险点
- `DATABASE_URL` 配错或权限不足
- 线上数据库可连但性能不稳定
- 某些接口仍隐式走 development/mock fallback

### 回滚点
- 先切回试运行环境变量
- 或直接回退到上一版 Netlify 发布

- 保留正式库不动，先停止对外使用当前版本
