# 正式数据版上线实施清单_2026-03-30

## 一、目标
本次实施目标是把当前系统从：

- Netlify 试运行演示模式

推进到：

- 正式数据版上线模式

并确保：
- 页面展示基于真实数据库
- 完整账款档案来自真实档案表
- 风控结果基于真实业务数据

---

## 二、实施清单

### 1. 建库
- 选择正式 PostgreSQL 托管服务
- 创建正式数据库实例
- 创建正式数据库账号
- 开启 Netlify 可访问的连接方式
- 获取正式 `DATABASE_URL`

验收看什么：
- 从本地可连
- 从 Netlify Runtime 可连

### 2. 执行 migration
- 在正式 `DATABASE_URL` 下执行 Prisma migration
- 确认 schema 与正式库一致

验收看什么：
- 核心表创建成功
- 无 migration 失败

### 3. 本地真实数据导出
- 导出本地 PostgreSQL 中的真实业务数据
- 优先包含：
  - 客户
  - 项目
  - 应收
  - 风险
  - 信用评分
  - 完整账款档案

验收看什么：
- 导出文件完整
- 行数与本地库一致

### 4. 线上数据库导入
- 先导主数据
- 再导完整账款档案
- 再导风控和辅助数据

验收看什么：
- 导入无报错
- 关键表数量合理

### 5. Netlify 环境变量配置
- 配置：
  - `DATABASE_URL`
  - `SITE_ACCESS_PASSWORD`

验收看什么：
- 构建不缺环境变量
- Runtime 可连库

### 6. 部署验证
- 触发 Netlify 正式数据版部署
- 查看构建日志
- 查看 Functions Runtime 日志

验收看什么：
- 构建通过
- 无 Prisma 初始化错误
- 无数据库连接错误

### 7. 页面级验证
至少验证：
- `/login`
- `/customers`
- `/customers/[id]`
- `/risk`
- `/risk/customers`
- `/risk/projects`

验收看什么：
- 客户详情页能显示真实完整账款档案
- 风控页面能显示真实风控结果

### 8. 样本级验证
建议抽样：
- 云龙小学
- 96#地块
- 青水澜湾
- 已诉 / 待起诉项目
- 高金额高未收项目

验收看什么：
- 页面值与数据库一致
- 风控结果符合规则

### 9. 回滚准备
- 保存部署前数据库快照
- 保存当前 Netlify 发布版本
- 确认可快速切回上一版

验收看什么：
- 有可执行回滚路径

---

## 三、执行顺序建议
1. 建正式库
2. 跑 migration
3. 导出本地真实数据
4. 导入正式数据库
5. 配 Netlify 环境变量
6. 发起部署
7. 做最小回归
8. 做重点样本验收
9. 确认交付

---

## 四、当前最优先动作
### 第一优先
拿到正式 PostgreSQL 和正式 `DATABASE_URL`

### 第二优先
完成本地真实数据到正式数据库的迁移演练

### 第三优先
部署到 Netlify 并做页面级回归

---

## 五、一句话结论
正式数据版上线现在最关键的不是再做页面，而是：

- **建正式库**
- **迁真实数据**
- **让 Netlify 正式连接真实数据库并完成回归**
