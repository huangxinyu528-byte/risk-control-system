# 正式数据版环境变量清单_2026-03-30

## 一、试运行必需

### 1. DATABASE_URL
- 用途：正式 PostgreSQL 数据库连接串
- 是否必填：是
- Build 用还是 Runtime 用：Build + Runtime
- 正式数据版是否必须：必须
- 示例：
  - `postgresql://USER:PASSWORD@HOST:5432/DB_NAME?schema=public`

### 2. SITE_ACCESS_PASSWORD
- 用途：站点访问密码
- 是否必填：是
- Build 用还是 Runtime 用：Runtime
- 正式数据版是否必须：建议保留

## 二、正式上线建议补充

### 3. DIRECT_DATABASE_URL
- 用途：供 Prisma migration / 运维工具使用的直连地址
- 是否必填：当前代码未接入，非必填
- Build 用还是 Runtime 用：运维 / CLI
- 正式数据版是否必须：建议后补

说明：
- 当前项目代码只消费 `DATABASE_URL`
- 如果后续数据库采用连接池地址，建议增加 `DIRECT_DATABASE_URL` 供 migration 使用

## 三、可后补

### 4. 未来第三方服务变量
当前第一版正式数据版不强依赖以下第三方：
- 天眼查真实接口变量
- OpenClaw 正式接口变量

所以这些变量当前不是正式数据版上线前置。

## 四、当前结论
正式数据版当前最小环境变量集合是：
- `DATABASE_URL`
- `SITE_ACCESS_PASSWORD`
